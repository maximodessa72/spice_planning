# 📊 Система планирования закупок специй и пряностей

Веб-приложение для автоматизированного планирования контейнерных поставок на 18 месяцев.

![Streamlit](https://img.shields.io/badge/Streamlit-FF4B4B?style=for-the-badge&logo=Streamlit&logoColor=white)
![Python](https://img.shields.io/badge/Python-3.9+-3776AB?style=for-the-badge&logo=python&logoColor=white)

## 🎯 О проекте

Система автоматически рассчитывает оптимальный план заказов для 24 товарных групп (специи, травы, орехи, овощи) с учётом:
- Буферов безопасности
- Циклов поставки
- Сезонности
- Размеров контейнеров
- Фиксированных приходов

**Результат:** 190 контейнеров на 4 922 000 кг на период апрель 2026 — сентябрь 2027

## ✨ Возможности

- **Автоматический пересчёт** при изменении остатков и планов
- **Интерактивный интерфейс** с редактированием данных
- **Визуализация** календаря заказов по группам
- **Детальный просмотр** буферов и приходов
- **Специальная балансировка** для корицы и сезонных товаров
- **Экспорт в Excel** (в разработке)

## 🎓 Логика расчётов

### Фиксированные заказы
Если месяц помечен как фиксированный (все позиции имеют явное значение в `in_transit`), система использует ТОЛЬКО указанные значения без балансировки.

### Балансировка контейнеров
Для НЕ фиксированных приходов:
1. Рассчитывается потребность каждой позиции
2. Контейнер распределяется пропорционально планам
3. Учитывается сезонность (корица, кардамон)
4. Округление до размера мешка (25 кг)

### Определение заказа
Заказ размещается когда:
```
будущий_баланс < общий_план × буфер
```

## 🎨 Цветовая схема буферов

| Буфер | Цвет | Статус |
|-------|------|--------|
| < 1.0 мес | 🟠 Персиковый | Критично |
| 1.0 - 1.25 мес | 🟡 Светло-жёлтый | Средне |
| ≥ 1.25 мес | 🟢 Светло-зелёный | Хорошо |
