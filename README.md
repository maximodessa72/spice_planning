# 📊 Система планирования закупок

Веб-приложение для автоматизированного планирования контейнерных поставок на 18 месяцев.

## ✨ Возможности

- **Автоматический пересчёт** при изменении остатков и планов
- **Интерактивный интерфейс** с редактированием данных
- **Визуализация** календаря заказов
- **Детальный просмотр** по группам и месяцам
- **Сезонность продуктов** - цветовая карта пиков потребления
- **Экспорт в Excel** (в разработке)

## 🚀 Быстрый старт

### 1. Установка Python

Если Python не установлен:
- **Windows**: скачайте с [python.org](https://www.python.org/downloads/) (версия 3.9 или выше)
- **Mac**: `brew install python3`
- **Linux**: `sudo apt install python3 python3-pip`

### 2. Установка зависимостей

Откройте терминал/командную строку в папке проекта и выполните:

```bash
pip install -r requirements.txt
```

### 3. Запуск приложения

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу `http://localhost:8501`

## 🎯 Использование

### Главная страница

Отображает:
- Общее количество контейнеров и объём
- Критичные группы (буфер < 1 месяц)
- Ближайшие заказы на 3 месяца

### Редактор данных

Позволяет изменять:
- Остатки на начало
- Планы потребления
- Просматривать фиксированные приходы

**После изменения данных нажмите кнопку "Пересчитать" в боковом меню!**

### Календарь заказов

Таблица всех групп × 18 месяцев с количеством заказов.

### Детальный просмотр

Подробная информация по выбранной группе:
- Остатки, приходы, буферы по месяцам
- Детали по позициям

### Сезонность

Визуализация сезонных колебаний потребления:
- **Тепловая карта** - все продукты × 12 месяцев с цветовой кодировкой интенсивности
- **Статистика** - количество продуктов с пиками в каждом месяце
- **Детализация** - список продуктов с пиками для выбранного месяца
- **Легенда** - 6 уровней интенсивности (от зелёного до голубого)

Данные загружаются из файла `сезонность.xlsx`

## 📊 Данные

Все данные с исправлениями находятся в файле `data.py`:

✅ **Морковь**: приход август (было июль)
✅ **Зира**: явный 0 в апреле
✅ **Куркума 2%**: явные 0 в апреле и июне
✅ **Куркума 3,5%**: явные 0 в апреле и июне

### Как изменить данные

**Вариант 1: Через веб-интерфейс** (рекомендуется)
1. Открыть "Редактор данных"
2. Выбрать группу
3. Изменить значения
4. Нажать "Пересчитать"

**Вариант 2: Редактировать файл `data.py`**
1. Открыть `data.py` в текстовом редакторе
2. Найти нужную группу в списке `GROUPS`
3. Изменить `balance`, `plan`, или `in_transit`
4. Сохранить файл
5. Перезапустить приложение

## 🔧 Конфигурация

### Константы (в файле `data.py`):

- `BUFFER_DEFAULT = 1.0` - буфер безопасности по умолчанию (1 месяц)
- `BUFFER_GROUP4 = 1.2` - буфер для чеснока (1.2 месяца)
- `BAG = 25` - размер мешка по умолчанию (25 кг)
- `N_MONTHS = 18` - горизонт планирования (18 месяцев)

## 📝 Примеры изменения данных

### Изменить остаток на начало

В `data.py` найти группу и позицию:

```python
{
    "name": "3б. Китай (морква)",
    "items": [
        {"name": "Морковь", "balance": 37617, ...}  # Изменить это значение
    ]
}
```

### Изменить план потребления

```python
{"name": "Морковь", "plan": 6000, ...}  # Изменить это значение
```

### Добавить фиксированный приход

```python
{"name": "Морковь", "in_transit": {4: 27000}, ...}  # mi=4 это август
```

Индексы месяцев (mi):
- 0 = Апр 2026
- 1 = Май 2026
- 2 = Июн 2026
- 3 = Июл 2026
- 4 = Авг 2026
- и т.д.

1. Проверьте что Python установлен: `python --version`
2. Установите зависимости: `pip install -r requirements.txt`
3. Попробуйте: `python -m streamlit run app.py`


### Изменения не сохраняются

После изменения данных обязательно нажмите кнопку **"Пересчитать"** в боковом меню!

## 🎓 Логика расчётов

### Фиксированные заказы

Если месяц помечен как фиксированный (все позиции имеют явное значение в `in_transit`), то:
- Система НЕ балансирует контейнер
- Используются ТОЛЬКО указанные значения
- Позиции без значения должны иметь явный `0`

### Балансировка

Для НЕ фиксированных приходов система:
1. Рассчитывает потребность каждой позиции
2. Распределяет контейнер пропорционально планам
3. Учитывает сезонность для специальных групп
4. Округляет до размера мешка

### Определение заказа

Заказ размещается когда:
```
будущий_баланс < общий_план × буфер
```

Где `будущий_баланс` = баланс через `cycle_months` при текущих приходах.
