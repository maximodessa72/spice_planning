# Инструкция по тестированию v7

## 🧪 Как протестировать новые функции

### 1. Тест: Буферы и риски — список групп
**Страница:** Планирование закупок → Аналитика по закупкам → раздел "Буферы и риски"

**Действия:**
1. Найти круговую диаграмму "Распределение групп по уровню буфера"
2. Навести мышку на любой сектор (Критично/Нормально/Хорошо)
3. **Ожидаемый результат:** Всплывающая подсказка показывает:
   - Название уровня
   - Количество групп
   - Процент
   - **Список всех групп** в этом уровне (с маркерами •)

---

### 2. Тест: Фиксация дат — отсутствие отладки
**Страница:** Планирование продаж → Фиксация даты прихода заказа

**Действия:**
1. Открыть страницу фиксации дат
2. Прокрутить вниз до кнопки "Сбросить все даты"
3. **Ожидаемый результат:** 
   - Блока "🔍 Отладка: Зафиксированные даты" **НЕТ**
   - Интерфейс чистый и компактный

---

### 3. Тест: Аналитика продаж — метрики остатков
**Страница:** Планирование продаж → Аналитика по продажам

**Предварительные условия:**
- Должны быть импортированы данные продаж (цены и план)
- Выполнен пересчёт закупок

**Действия:**
1. Открыть страницу аналитики продаж
2. **Ожидаемый результат вверху:**
   - 3 метрики:
     - "Позиций с остатком < плана"
     - "Позиций с остатком < 50% плана"
     - "% критичных позиций"
3. **Ожидаемый результат ниже:**
   - График "Количество позиций с недостаточным остатком"
   - Две линии: оранжевая (< план) и красная (< 50% плана)
   - 12 месяцев на оси X

**Проверка значений:**
- Значения должны быть >= 0
- Красная линия всегда <= оранжевой
- График показывает динамику по месяцам

---

### 4. Тест: Импорт закупок — новый интерфейс
**Страница:** Планирование закупок → Импорт данных по закупкам

#### 4.1 Тест закладок
**Действия:**
1. Открыть страницу импорта данных по закупкам
2. **Ожидаемый результат:**
   - Вместо "Шаг 1" и "Шаг 2" есть **две закладки**:
     - "📦 Остатки из программы"
     - "📊 Планы закупок"
3. Переключиться между закладками
4. **Ожидаемый результат:** Содержимое меняется, интерфейс работает

#### 4.2 Тест нового формата планов
**Действия:**
1. Перейти на закладку "📊 Планы закупок"
2. Загрузить тестовый файл `план_закупок.xlsx` (приложен к проекту)
3. **Ожидаемый результат:**
   - Файл успешно загружен
   - Показывается таблица изменений
   - Для сезонных позиций отображается "не меняется"
   - Метрики: "Найдено изменений" и "Не найдено в проекте"

**Формат тестового файла:**
```
Колонка A: Название позиции
Колонка B: Количество (кг)
```

Пример содержимого:
```
Группа / Позиция
(пусто)
1. Єгипет (трави)
(пусто)
Базилік зелень (В)
4903
...
```

4. Нажать "✅ Применить планы"
5. **Ожидаемый результат:**
   - Планы обновлены
   - Выполнен пересчёт
   - Показан success-баллун

## 🐛 Возможные проблемы и решения

### Проблема 1: Аналитика продаж показывает ошибку
**Причина:** Не импортированы данные продаж
**Решение:** Перейти в "Импорт данных по продажам" и загрузить цены и план

### Проблема 2: График буферов не показывает список групп
**Причина:** Возможно кэширование старой версии
**Решение:** 
1. Обновить страницу (Ctrl+F5)
2. Проверить что приложение перезапустилось после git push

### Проблема 3: Импорт планов не работает с новым файлом
**Причина:** Неправильный формат файла
**Решение:**
- Проверить что файл имеет 2 колонки
- Проверить что заголовки групп имеют пустое значение во 2-й колонке
- Посмотреть на пример файла `план_закупок.xlsx`
