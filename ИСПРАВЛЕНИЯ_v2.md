## ЛОГИКА РАБОТЫ ТЕПЕРЬ:

### При редактировании недели заказа:
1. Пользователь меняет неделю в форме редактирования
2. `week_arrival[mi] = new_week` сохраняется
3. Вызывается `run_all_simulations()`
4. **simulation.py** видит `week_arrival[i]` и использует его вместо расчёта из буфера
5. Результат: `wl = "Тиж. 3"` (зафиксированная неделя)
6. **sales_export.py** использует этот `wl` для расчёта рабочих дней
7. Excel показывает правильную неделю и пересчитанные остатки ✅

### При фиксации даты прихода:
1. Пользователь выбирает новую дату (например, 15-е число)
2. Вычисляется `week_number = (15-1)//7 + 1 = 3`
3. `week_arrival[mi] = 3` сохраняется
4. `arrival_fixed_dates[group_name] = datetime(...)` сохраняется
5. Вызывается `run_all_simulations()`
6. **simulation.py** видит `week_arrival[i]=3` → `wl = "Тиж. 3"`
7. **sales_export.py** видит `arrival_fixed_dates` → точные рабочие дни
8. Excel показывает новую дату, неделю 3, пересчитанные остатки ✅
