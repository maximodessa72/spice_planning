# ИСПРАВЛЕНИЕ: Пересчёт остатков с учётом недели прихода

## ПРОБЛЕМА

В "План + Балансування" при изменении недели заказа:
- ✅ Неделя в Excel меняется
- ✅ Килограммы позиций НЕ меняются (фиксированный заказ)
- ❌ **Остатки НЕ пересчитываются**

## ПРИЧИНА

Остатки рассчитывались по простой формуле:
```python
balance = balance + arrive - plan_месяца
```

Эта формула НЕ учитывала **когда в течение месяца** пришёл товар.

## ЛОГИКА РЕШЕНИЯ

### Пример: Петрушка
```
Остаток на начало: 0 кг
План: 4000 кг/мес
Приход: 5000 кг

Неделя 1 (5-е число):
  Рабочих дней после прихода: 17 из 21
  Продадим: 4000 × (17/21) ≈ 3238 кг
  Остаток на след. месяц: 5000 - 3238 = 1762 кг

Неделя 3 (15-е число):
  Рабочих дней после прихода: 10 из 21
  Продадим: 4000 × (10/21) ≈ 1905 кг
  Остаток на след. месяц: 5000 - 1905 = 3095 кг
```

### Два случая:

**СЛУЧАЙ 1: Товара хватало (остаток ≥ план)**
```python
# Товар был весь месяц, продали полный план
balance_end = balance_start + arrive - plan_full
```

**СЛУЧАЙ 2: Товара НЕ хватало (остаток < план)**
```python
# Ждали приход, продали только после прихода
day = get_arrival_day(week_label)  # 5, 10, 15, 20
plan_after = plan_full × (days_after / 21)
balance_end = arrive - plan_after
```

## РЕАЛИЗАЦИЯ

### 1. Добавлены функции (строки 40-95)

```python
def get_arrival_day_from_week(week_label: str) -> int:
    """
    пред.мес / Тиж. 1 → 5-е число
    Тиж. 2 → 10-е число
    Тиж. 3 → 15-е число
    Тиж. 4 → 20-е число
    """
    if "пред" in week_label.lower() or "1" in week_label:
        return 5
    elif "2" in week_label:
        return 10
    elif "3" in week_label:
        return 15
    elif "4" in week_label:
        return 20
    else:
        return 5

def calculate_proportional_plan(monthly_plan: float, arrival_day: int) -> float:
    """
    Рассчитать пропорциональный план с учётом оставшихся дней
    
    День → Дней после → Коэффициент
    5    → 17        → 17/21 = 0.81
    10   → 14        → 14/21 = 0.67
    15   → 10        → 10/21 = 0.48
    20   → 6         → 6/21 = 0.29
    """
    days_mapping = {
        5: 17,   # неделя 1
        10: 14,  # неделя 2
        15: 10,  # неделя 3
        20: 6    # неделя 4
    }
    days_after = days_mapping.get(arrival_day, 17)
    return monthly_plan * (days_after / 21)
```

### 2. Изменён расчёт balance группы (строка ~430)

**БЫЛО:**
```python
balance = max(0, balance + arrive - tpi)
```

**СТАЛО:**
```python
balance_start = balance  # Остаток на начало

if balance_start >= tpi:
    # СЛУЧАЙ 1: Товара хватало
    balance = balance_start + arrive - tpi
elif arrive > 0:
    # СЛУЧАЙ 2: Товара не хватало, ждали приход
    arrival_day = get_arrival_day_from_week(wl)
    plan_after_arrival = calculate_proportional_plan(tpi, arrival_day)
    balance = max(0, arrive - plan_after_arrival)
else:
    # СЛУЧАЙ 3: Нет прихода
    balance = max(0, balance_start - tpi)
```

### 3. Изменён расчёт item_state позиций (строка ~395)

**БЫЛО:**
```python
for it in group["items"]:
    item_state[it["name"]] = max(0, item_state[it["name"]] + ia[it["name"]] - get_plan(it, i))
```

**СТАЛО:**
```python
for it in group["items"]:
    item_balance_start = item_state[it["name"]]
    item_arrival = ia[it["name"]]
    item_plan = get_plan(it, i)
    
    if balance_start >= tpi:
        # Товара хватало — полный план
        item_state[it["name"]] = max(0, item_balance_start + item_arrival - item_plan)
    elif arrive > 0 and item_arrival > 0:
        # Товара не хватало — пропорциональный план
        arrival_day = get_arrival_day_from_week(wl)
        item_plan_after = calculate_proportional_plan(item_plan, arrival_day)
        item_state[it["name"]] = max(0, item_arrival - item_plan_after)
    else:
        # Нет прихода
        item_state[it["name"]] = max(0, item_balance_start - item_plan)
```
