# ИСПРАВЛЕНИЕ: UnboundLocalError для balance_start

## ОШИБКА
```
UnboundLocalError: cannot access local variable 'balance_start' 
where it is not associated with a value
```

## ПРИЧИНА

Переменная `balance_start` использовалась в двух местах:

1. **Строка ~400** — в цикле обновления `item_state`:
   ```python
   if balance_start >= tpi:  # ❌ balance_start ещё не определён!
   ```

2. **Строка ~451** — при расчёте `balance`:
   ```python
   balance_start = balance  # ✅ Определение
   ```

Переменная использовалась раньше чем была определена!

## ИСПРАВЛЕНИЕ

Перенёс определение `balance_start` **ПЕРЕД** циклом обновления `item_state`:

```python
# Сохраняем остаток на начало месяца для расчётов
balance_start = balance  # ✅ Определяем в начале

# Обновляем остатки позиций
for it in group["items"]:
    if balance_start >= tpi:  # ✅ Теперь переменная определена
        ...
```

И убрал дублирующее определение в блоке расчёта `balance`.

## РЕЗУЛЬТАТ

✅ Ошибка исправлена  
✅ `balance_start` определяется один раз в правильном месте  
✅ Используется в обоих блоках кода
