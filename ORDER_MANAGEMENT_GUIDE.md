# Руководство по управлению заказами

## Обзор

В разделе **"📦 Подтверждение заказов" → вкладка "📋 Подтверждённые заказы"** доступны расширенные функции управления подтверждёнными заказами.

## Функции управления заказами

Для каждого подтверждённого заказа доступно **4 колонки с кнопками**:

### 1️⃣ Скачать спецификацию
- **Кнопка:** `📥 Скачать спецификацию`
- **Функция:** Создаёт Excel-файл с детальной спецификацией заказа
- **Содержит:**
  - Название группы
  - Месяц прихода
  - Общий вес
  - Таблица всех позиций с весами
- **Формат имени:** `Спецификация_{Группа}_{Месяц}.xlsx`

### 2️⃣ Смещение заказа
- **Кнопки:** `⬅️ На месяц назад` / `➡️ На месяц вперёд`
- **Функция:** Перемещает заказ на соседний месяц
- **Особенности:**
  - Нельзя переместить в прошлое (до текущего стартового месяца)
  - Автоматически переносит все данные группы и позиций
  - Переносит номер недели прихода (если указан)
  - Автоматически пересчитывает всю систему
- **Применение:** Когда производитель подтвердил другую дату отгрузки

### 3️⃣ Редактировать заказ
- **Кнопка:** `✏️ Редактировать`
- **Функция:** Открывает форму редактирования комплектации заказа
- **Возможности:**
  - Изменение веса каждой позиции
  - Удаление позиций (установка веса = 0)
  - Изменение номера недели прихода
  - Сохранение или отмена изменений
- **Автоматика:**
  - Если общий вес = 0 → заказ удаляется полностью
  - Если вес позиции = 0 → позиция удаляется из заказа
  - После сохранения система автоматически пересчитывается
- **Применение:** Когда производитель изменил комплектацию контейнера

### 4️⃣ Удалить заказ
- **Кнопка:** `🗑️ Удалить заказ`
- **Функция:** Полное удаление заказа из всех расчётов
- **Действия:**
  - Удаление из группы (`in_transit`)
  - Удаление из всех позиций группы
  - Удаление номера недели прихода
  - Автоматический пересчёт системы
- **ВНИМАНИЕ:** Действие необратимо! Заказ будет полностью удалён.
- **Применение:** Когда заказ был отменён производителем

## Модальное окно редактирования

При нажатии кнопки `✏️ Редактировать` появляется форма редактирования:

```
✏️ Редактирование заказа: Название группы
Месяц прихода: МАЙ 2026

Текущая комплектация:

**Позиция 1**           [______ кг]
**Позиция 2**           [______ кг]
**Позиция 3**           [______ кг]

────────────────────────────────
Общий вес после изменений: X,XXX кг

Номер недели прихода: [_]

[💾 Сохранить изменения]  [❌ Отменить]
```

### Поля формы
- **Вес позиций:** Поля ввода с шагом 100 кг (можно установить 0 для удаления)
- **Номер недели:** 0 = не указано, 1-4 = номер недели месяца
- **Общий вес:** Автоматически рассчитывается

### Кнопки формы
- **💾 Сохранить изменения** — применить изменения и пересчитать систему
- **❌ Отменить** — закрыть форму без изменений

## Типичные сценарии использования

### Сценарий 1: Производитель изменил дату отгрузки
**Проблема:** Контейнер приедет не в мае, а в июне  
**Решение:** Кнопка `➡️ На месяц вперёд`

### Сценарий 2: Производитель изменил комплектацию
**Проблема:** Вместо 5000 кг зиры будет 4500 кг, остальное — кориандр  
**Решение:**
1. Кнопка `✏️ Редактировать`
2. Зира: 5000 → 4500
3. Кориандр: добавить недостающий вес
4. `💾 Сохранить изменения`

### Сценарий 3: Заказ отменён производителем
**Проблема:** Контейнер не приедет вообще  
**Решение:** Кнопка `🗑️ Удалить заказ`

### Сценарий 4: Нужно отправить спецификацию поставщику
**Проблема:** Требуется Excel-файл для подтверждения  
**Решение:** Кнопка `📥 Скачать спецификацию`

## Технические детали

### Структура данных заказа
```python
# Группа
group["in_transit"][mi] = total_weight  # Общий вес на месяц mi

# Позиции
item["in_transit"][mi] = item_weight    # Вес позиции на месяц mi

# Номер недели (опционально)
group["week_arrival"][mi] = week_num    # 1-4
```

### Автоматические действия
1. **При смещении заказа:**
   - Перенос `in_transit` группы
   - Перенос `in_transit` всех позиций
   - Перенос `week_arrival` (если есть)
   - Пересчёт системы

2. **При редактировании:**
   - Обновление весов позиций
   - Удаление позиций с весом = 0
   - Обновление общего веса группы
   - Обновление/удаление номера недели
   - Пересчёт системы

3. **При удалении:**
   - Полная очистка `in_transit` группы и позиций
   - Удаление `week_arrival`
   - Пересчёт системы

### Пересчёт системы
После любого изменения заказа автоматически вызывается:
```python
st.session_state.results = run_all_simulations(st.session_state.groups)
st.session_state.need_recalc = False
```

## Фильтрация заказов

В верхней части списка доступен фильтр:
```
Показать заказы группы: [Все группы ▼]
```

Опции:
- **Все группы** — показать все подтверждённые заказы
- **Конкретная группа** — показать только заказы выбранной группы

Счётчик: `Показано заказов: X из Y`

## Интеграция с системой

Все изменения подтверждённых заказов **немедленно влияют** на:
- 📊 Главную страницу (буферы, заказы, критические группы)
- 📅 Планирование закупок (новые заказы учитывают изменения)
- 🚚 Календарь поставок (обновлённые даты и веса)
- 📥 Экспорт в Excel (актуальные данные)
