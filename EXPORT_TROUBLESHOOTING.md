# 🔧 УСТРАНЕНИЕ ПРОБЛЕМ С ЭКСПОРТОМ

## Если экспорт не работает в Streamlit

### ✅ Что было исправлено:

**ПРОБЛЕМА:** Кнопка скачивания исчезала после нажатия "Экспорт в Excel"

**ПРИЧИНА:** В Streamlit после нажатия кнопки происходит перезапуск приложения (rerun), и блок внутри `if st.button()` больше не выполняется.

**РЕШЕНИЕ:** 
1. Файл сохраняется в `st.session_state.excel_file` (в памяти)
2. Кнопка скачивания находится ВНЕ блока `if st.button()`
3. Кнопка видна всегда, когда файл создан

### 📋 Обновлённые файлы:

1. **app.py** - исправлена логика экспорта:
   ```python
   # Создание файла
   if st.button("💾 Экспорт в Excel"):
       # ... создаём файл ...
       with open(output_path, 'rb') as f:
           st.session_state.excel_file = f.read()  # Сохраняем в памяти
   
   # Кнопка скачивания (отдельно!)
   if st.session_state.excel_file is not None:
       st.download_button(
           label="📥 Скачать план_балансировка.xlsx",
           data=st.session_state.excel_file,
           ...
       )
   ```

2. **excel_export.py** - полная реализация с форматированием

### 🚀 Как использовать:

1. Запустите: `streamlit run app.py`
2. Нажмите **"💾 Экспорт в Excel"** в боковом меню
3. Подождите сообщения "✅ Excel файл создан!"
4. Нажмите **"📥 Скачать план_балансировка.xlsx"** (кнопка появится под "Экспорт")

### 🧪 Тестирование вне Streamlit:

Если нужно просто создать файл без запуска Streamlit:


### ❓ Частые вопросы:

**Q: Кнопка "Скачать" не появляется**
A: 
1. Проверьте консоль браузера (F12) на ошибки
2. Убедитесь что появилось сообщение "✅ Excel файл создан!"
3. Попробуйте обновить страницу (F5) и нажать "Экспорт" ещё раз

**Q: Ошибка "ModuleNotFoundError: No module named 'excel_export'"**
A:
1. Убедитесь что файл `excel_export.py` находится в той же папке что и `app.py`
2. Перезапустите Streamlit: Ctrl+C и заново `streamlit run app.py`

**Q: Ошибка "PermissionError" при создании файла**
A:
1. Файл создаётся во временной папке `/home/claude/`
2. Проверьте права доступа к папке

**Q: Excel файл пустой или с ошибками**
A:
1. Проверьте что симуляция выполнена (нажмите "🔄 Пересчитать")
2. Посмотрите текст ошибки в красном блоке
3. Запустите тестовый скрипт (см. выше) для диагностики

### 📊 Проверка корректности:

После скачивания откройте файл в Excel и проверьте:

1. **Заголовок (A1):** "План поставок + Балансування..."
2. **Месяцы (строка 3):** Апр 2026, Май 2026, Июн 2026...
3. **Морковь (строка 39, август):** Приход должен быть коричневым с "27 000\n⚠️ пред.міс"
4. **Буферы:** Должны быть раскрашены персиковым/жёлтым/зелёным
5. **Размер файла:** ~44 КБ
6. **Количество строк:** ~113 (24 группы + все позиции)

### 💡 Советы:

- **Используйте session_state** для хранения состояния между перезагрузками
- **Разделяйте кнопки**: кнопка действия (экспорт) и кнопка результата (скачать)
- **Сохраняйте данные в памяти** (`st.session_state`), а не только на диске
- **Показывайте прогресс** с помощью `st.spinner()` и `st.success()`

### 🔍 Отладка:

Если видите ошибку, включите детальный вывод:

```python
except Exception as e:
    st.error(f"❌ Ошибка: {str(e)}")
    import traceback
    st.code(traceback.format_exc())  # Покажет полный traceback
```
