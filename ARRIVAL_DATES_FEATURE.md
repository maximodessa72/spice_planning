# Функция фиксации дат прихода контейнеров

## Описание функции

Позволяет фиксировать точные даты прихода контейнеров для текущего месяца, что автоматически пересчитывает план продаж с учётом реальных рабочих дней после прихода товара.

---

## Как работает

### 1. Страница "Фиксация даты прихода заказа"

**Расположение:** Планирование продаж → Фиксация даты прихода заказа

**Функционал:**
- Показывает все приходы **текущего месяца** (май 2026)
- Только заказы где `in_transit=True` и `arrival_kg > 0`
- Отображает: группа, тип (контейнер/балансировка), вес, неделя, дата, статус

**Автоматические даты по неделям:**
- `пред мес` / `нед 1` → 5-е число
- `нед 2` → 10-е число
- `нед 3` → 15-е число
- `нед 4` → 20-е число

**Интерфейс:**
- Выбор заказа из списка
- Календарь выбора новой даты (только в пределах текущего месяца)
- Кнопка "💾 Зафиксировать"
- Кнопка "🔄 Сбросить все даты на автоматические"
- Раздел "🔍 Отладка" — показывает зафиксированные даты

### 2. Хранение данных

```python
st.session_state.arrival_fixed_dates = {
    "1. Єгипет (трави)": datetime(2026, 5, 12),
    "9. Індія (кунжут)": datetime(2026, 5, 7),
    ...
}
```

### 3. Интеграция в Excel продаж

**При создании Excel:**

1. **Передача данных:**
```python
create_sales_excel(
    ...
    arrival_fixed_dates=st.session_state.get("arrival_fixed_dates", {}),
    ...
)
```

2. **Отображение в строке группы:**
- Если текущий месяц (mi=0) И есть зафиксированная дата → показывает **12.05**
- Иначе → показывает **нед.2**

3. **Расчёт рабочих дней:**

**Функция:** `calculate_working_days_for_month(mi, group_name, week_label, arrival_kg, arrival_fixed_dates)`

**Логика:**
- Текущий месяц (mi=0) + зафиксированная дата → точный расчёт через `calculate_working_days_exact()`
- Иначе → расчёт по неделям (21/16/11/5 дней)

**Функция:** `calculate_working_days_exact(arrival_date, month_end)`
- Считает рабочие дни (Пн-Пт) с **дня после прихода** до конца месяца
- Исключает день прихода (товар приходит вечером)

4. **Пересчёт плана продаж:**

План пересчитывается для:
- **Итогов по группе** (строка группы)
- **Каждой позиции** в группе
- **Строки ИТОГО** внизу таблицы

**Формула плана:**
```python
plan = min(
    остаток + (рабочие_дни × план_на_день),
    план_базовый,
    остаток + приход
)
```

**Индексы:**

- ...

## Пример использования

### Сценарий:

1. **Группа:** "9. Індія (кунжут)"
2. **Автоматическая дата:** 20.05.2026 (нед.4)
3. **Автоматические рабочие дни:** 5 дней
4. **Зафиксированная дата:** 07.05.2026
5. **Точные рабочие дни:** 18 дней (с 08.05 до 31.05, Пн-Пт)

### Результат:

**До фиксации:**
- Неделя: "нед.4"
- Рабочие дни: 5
- План: остаток + (5 × план_на_день)

**После фиксации:**
- Дата: "07.05"
- Рабочие дни: 18
- План: остаток + (18 × план_на_день)

**Разница:** План увеличился в ~3.6 раза за счёт большего количества рабочих дней!

## Ограничения

1. **Только текущий месяц:** Фиксация работает только для текущего месяца (май 2026)
2. **Только приходы:** Показываются только заказы с `in_transit=True` и `arrival_kg > 0`
3. **Даты в пределах месяца:** Календарь ограничен 1-28 числом текущего месяца
4. **Сброс при перезапуске:** `session_state` не сохраняется между перезапусками Streamlit
